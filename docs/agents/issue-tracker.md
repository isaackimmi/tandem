# Issue tracker

Tandem uses Notion tasks and linked microplans, not GitHub issues. Read docs/requirements.md for the current agreed contract. Each PR body links its originating task(s); fetch those task pages and their plan relation when reviewing scope. Current design: https://app.notion.com/p/3fde7d562b818163a880ec86a955225f

Review each PR against its base branch and check the integrated stack against the full product contract. User authorization allows merging required PRs only after agent review, relevant tests, and manual MP4 evidence. Leave the optional Vercel deployment PR unmerged.
